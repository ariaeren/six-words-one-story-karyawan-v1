# Six Words, One Story

A deterministic, dependency-free Node 22 program that writes one complete six-word story to `${MAKEFUN_OUTPUT_DIR}/entry.txt` (default `/output`). No network calls, no secrets, and no dynamic code execution.

## The entry

`He proposed; she archived the draft.`

## Run

```sh
node main.ts
```

The destination directory can be overridden with `MAKEFUN_OUTPUT_DIR`.
